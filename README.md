# Summer Blouse Performance and Pricing Diagnostics (ZARA)

## Question
Why did blouses sell worse in summer?

## Data
660 ZARA products, 2018 to 2022: category, season, price, units sold, stock-outs, ratings.

## What the dashboard shows
1. Yearly blouse sales trend
2. Seasonal sales breakdown by category
3. Summer pricing diagnostics
4. Summer stock diagnostics

## Findings
- Average units sold per blouse fell from 320 in spring to 267 in summer.
- In summer, jeans (313 per item) and skirts (301) outsold blouses per item.
- The highest-priced summer item was a blouse at $149.88.
